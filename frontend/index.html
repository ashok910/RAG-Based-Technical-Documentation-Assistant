⚙️ Design Decisions

ComponentDecisionRationale
ChunkingRecursiveCharacterTextSplitter, size=800, overlap=100Respects paragraph/sentence boundaries; 800 chars is ~200 tokens, preserving context without noise
Embeddingsall-MiniLM-L6-v2 (local)Free, fast, 384-dim, no API key required; strong retrieval quality for technical text
Vector StoreChromaDB (default) or FAISSChroma persists automatically; FAISS is faster at scale — configurable via env
LLMPluggable: Groq / OpenAI / Gemini / AnthropicProvider-agnostic via factory; Groq recommended (free, fast llama3)
GradingPer-chunk LLM binary relevance judgeFilters noise before generation; reduces hallucination risk
Self-correctionRewrite + retry loop (max 2 by default)Handles vocabulary mismatch between query and docs; bounded to prevent loops
Hallucination CheckPost-generation groundedness score 0–1Self-RAG inspired; flags answers not supported by retrieved context
MemorySession-scoped chat history passed in each requestStateless API is simpler and scalable; client manages history
